連結本地 AI Agent

沿用 Cluster PowerShell 本地 Agent；初次使用只需下載單一 Quick-Setup.cmd，並依提示完成配置。

完成本地 Agent 配對與 MCP 授權後，可於此查看操作狀態與輸出。

01 · QUICK SETUP

下載 Quick-Setup.cmd 後直接執行；會自動取得必要檔案。 若 43879 被占用，可選擇 P／C／O。

02 · PS BIND / PAIRING TOKEN

請在可信任的主頁配對視窗輸入 64 字元 Token，金鑰不交給插件。

03 · VERIFY

配對成功後切換至運行狀態；若使用 P 模式，請填入選擇的新埠。

連接 ChatGPT / Connect ChatGPT
  1. 點選「下載 Quick-Setup.cmd」，不需下載整個插件 ZIP。
  2. 執行 Quick-Setup.cmd，依提示安裝依賴。埠占用時可選 P 改埠、C 取消、O 驗證後強制停止。
  3. 將 CMD 顯示的 Token 與埠號填入主頁可信任配對視窗。
  4. 點選「模型設定」，在可信任視窗設定 OpenAI API Key 與模型。
  5. 再點選「下載 MCP 快速配置 CMD」執行本機 MCP 配置。它會準備 43880 MCP 與選用的 43881 OAuth；不會自動架設公開 HTTPS。
  6. 設定可信任的固定 HTTPS 反向代理，僅指向本機 127.0.0.1:43881，網址必須與 OAuth Issuer 完全一致。
  7. 在 ChatGPT 設定自訂 MCP 連線：貼上 https://你的網域/mcp，使用 OAuth 登入，於授權頁輸入本機顯示的授權密碼。
  8. 預設 cluster.read 僅提供五項唯讀工具。若需遠端檔案 CRUD／PowerShell，必須明確要求 cluster.control、在 OAuth 頁面同意高權限警告，再於 Cluster ToolBox 分別開啟檔案與 PS 權限。
  9. 每一條 PowerShell 命令仍須在 Cluster 視窗確認，關閉 ToolBox 對應權限即可拒絕後續請求。
