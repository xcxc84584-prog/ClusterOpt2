✧ AI Agent 尚未連線

連結本地 AI Agent

沿用 Cluster PowerShell 本地 Agent；初次使用請下載 Quick-Setup.cmd 配置。

完成本地 Agent 配對與 MCP 授權後，可於此查看操作狀態與輸出。

01 · QUICK SETUP

下載 Quick-Setup.cmd 後直接執行；會自動取得必要檔案。 若 43881 被占用，可選擇 P／C／O。

02 · PS BIND / PAIRING TOKEN

請在可信任的主頁配對視窗輸入 64 字元 Token，金鑰不交給插件。

03 · VERIFY

配對成功後切換至運行狀態；若使用 P 模式，請填入選擇的新埠。

連接 ChatGPT / Connect ChatGPT
  1. 下載完整 AI AGENT MCP(ChatGPT) 插件 ZIP 並在插件管理裝載。
  2. 下載 Local Agent Quick-Setup.cmd，啟動本地 Agent。 安裝器支援 C／P／O；配對預設使用 43881。
  3. 複製本地 Agent 顯示的配對 Token， 在主畫面配對視窗輸入 Token 與埠號。
  4. 在 ToolBox 選取授權資料夾， 再依需求個別允許 Read／Create／Update／Delete／PowerShell。
  5. 下載 MCP Quick-Setup.cmd，啟動本地 MCP 43880 和 OAuth 43879，保留本地服務視窗。
  6. 建立固定名稱 clusteropt2 的公開 HTTPS 網域 （需自行擁有 DNS 與有效 TLS 憑證）。 只將 HTTPS 代理到 OAuth Gateway 的本機 43879。
  7. 在 ChatGPT 新增自訂 MCP 連線， 輸入完整 HTTPS 網址加上 /mcp，完成 OAuth 授權。
  8. cluster.read 只有五項唯讀工具； cluster.control 必須另行同意授權，且檔案及 PS 指令 仍需要 ToolBox／逐命令確認。
