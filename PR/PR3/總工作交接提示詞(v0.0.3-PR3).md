## 全局 OCDA SOP（每次延續必讀）
1. 先讀 `全域屬性清單.md`，避免重複註冊 Property。
2. 程式碼清楚命名、明確註解、有限行長、Tab 縮排對齊，
   統一風格，禁止硬編碼 API 金鑰或機器絕對路徑。
3. 每個 Object、Property 獨立檔案。標準物件具有 EHU/Log、
   Request、Response、User API、Agent API、Property、Program。
4. 物件間經 HubUnit 的 Request/Response 互動；
   URU 管註冊、EDPMU 管共享 Property、OMU 管 EHU/Log/Dependency。
5. Relation Code：00/10/01/11；Public/Private/Protected；
   SubObject 以完整 ObjectPath 解析。
6. 依 PRD → Plan → ArcD → Implementation + Relation Test → Project。
7. 每次 Patch 更新 `PR/PRx/Plan.md`、`ArcD.md`、
   `Patch(+n).md`、RelationTest 和版本化交接檔。
8. Object API 為手、Property 演算法為腦；分析 Event Chain，
   依資料競態決定是否適合平行化。
9. 界面直接沿用舊 ClusterOpt，禁止自行重新設計。
