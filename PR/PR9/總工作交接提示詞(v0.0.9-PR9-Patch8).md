## Problem
User photo shows the PS prompt displaced under footer, with literal
backslash-r/backslash-n before Native terminal disconnected.
User also needs to copy port/token and then close CMD while the native
Agent remains running in background.

## Fix
- xterm 5.3 + FitAddon 0.8, ResizeObserver and flex min-height:0;
  keep native input visible within .psm-native-wrap.
- Actual CRLF control bytes in terminal status messages.
- Native socket status separate from HTTP agent Connected.
- Install-current.ps1: random ephemeral 64-hex token, env handoff
  to a hidden detached Node process, successful listen check,
  display port/token, wait for user to copy, then exit CMD.
- server.mjs: accept validated env bootstrap token, delete env var
  before native PowerShell children inherit environment.
- CMD no pause on successful installer completion, pauses on error.
- node-pty import health check after npm install, fail clearly
  when native build script was not approved.
- Versions from LinkCore, not a second hard-coded UI constant.
