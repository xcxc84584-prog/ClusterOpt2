## Core semantics
- Workspace Save of a dirty virtual doc starts detached writeback
  and immediately returns. Per-document saveActive/saveProgress
  survives tab changes. UI progress is blue 0–99 until disk readback
  and journal retirement succeed.
- Large Save copies whole source in 64KiB chunks and yields after
  eight chunks; progress covers copy and verification.
- User editing while Save active sends a separate Hub cancel before
  editing; AbortSignal cancels before stream close.
- FileWorkspace tracks savePromise for an active background save;
  closing that file awaits the existing task instead of starting
  a duplicate write or returning 409.
- After stream close, verify and retire journal then process edits.
- On abort/failure, preserve dirty status and durable checkpoint.
- Save task cancellation must never delete user edits.
- Do not re-render Explorer/tabs per chunk; only paint active status.
- 1/5GiB stress, manual Windows file permissions and crash recovery
  remain OPEN. PR8 NOT PASS.
