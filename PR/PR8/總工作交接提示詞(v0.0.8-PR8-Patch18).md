## Safety contract
- Files over 64 MiB open via a bounded 64 KiB Blob page rather
  than FileDocument's full-string loader.
- Virtual pages build immutable Piece Tree and B+ position index,
  but remain read-only until true virtual editing is implemented.
- UI uses existing textarea, tabs, status and Explorer; wheel at
  page boundaries or Alt+PageDown/Up navigates adjacent pages.
- Save/Edit from a partial page must fail 409; prior small-file
  editing stays unchanged. FileDocument.save has a disk-size guard.
- Recovery stores virtual marker/handle/page index only, never
  partial page text. Reload should reopen correct page from disk.
- Source modified externally blocks page load, unless explicitly
  reloaded under ExternalFirst policy.
- Progress shows the current page request only.
- PAGE LOCAL line numbers currently; global line/viewport model
  and editable MVCC integration are not complete.
