## Scope and risk notes

`transactDurable` persists first, then updates in-memory immutable
Piece Tree root. `restoreDurable` reconstructs verified revision.
Current object is a standalone sandbox, NOT wired to FileDocument or
real file writeback. Dirty close still returns 409.
Atomic cross-tab IndexedDB revision CAS is implemented in
IndexedDBSliceJournalStore.putIfNewer, but real browser multi-tab
verification now has E2E test coverage; latest CI confirmation is OPEN.

fault injection, viewport position and whole-file recovery.
