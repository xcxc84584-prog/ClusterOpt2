## Architecture invariants
- Object contains EHU/Log, Request, Response, UserAPI, AgentAPI,
  Property, Program; independent Object and Property source files.
- Every cross-object Request/Response through HubUnit with OMU
  Log/EHU and directed Dependency (00/10/01/11).
- LinkCore=HubUnit+ObjectManagementUnit+
  EntireDomainPropertyManagementUnit+UnifiedRegistrationUnit.
- URU registration is dynamic on page load; no stale cached
  registration assumptions. LinkCore owns changing SystemVersion.
- Authorization Public/Protected/Private; SubObject full paths.
- Parallelism must respect same-document FIFO and version CAS.
- SOP: PRD -> Plan -> ArcD -> Implementation+Relation Test -> Project.
- Clean consistent code, no absolute paths, embedded keys or dev
  prompts in user UI. Reuse ClusterOpt original visual styling.

## Important limitations for Patch20/23
- Line-prefix scan is O(bytes since nearest checkpoint), bounded
  memory but cold fast jumps can be slow; optimize async cache.
- One editable page at a time; dirty pages cannot unload or switch.
- Save streams and verifies the entire disk file, O(file bytes);
  optimize parallel and incremental writeback carefully.
- Page text is bounded; no whole-document textarea or DOM gutter.
- File edit ID and original fingerprint are stored in metadata-only
  session recovery. Browser quota/power loss and cross-tab identity
  races still need extensive fault-injection.
- Cross-page multi-slice edit, global line jump, true viewport
  virtual scroll and 1/5GiB tests remain OPEN.
- Do not prematurely claim PR8 PASS.
