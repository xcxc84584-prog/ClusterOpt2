Requests/Responses; URU owns dynamic Object identity; OMU records
Log/EHU and dependency. Property is validation-only, not a new EDPMU
global entry. No hardcoded key, no machine absolute paths, no debug UI.

and explicit user consent. Don't mistake network.request approval for
permission to execute tools or model API calls.
