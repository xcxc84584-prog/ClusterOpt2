## Critical limits
This is an executable **contract-only** plugin; it does not yet provide
a button, AI model, pairing, Explorer, shell, MCP or OAuth. Never imply
a connected model based on getStatus. PR13 host currently does not
provide execution of uiEntry or multi-file JS graph and rejects
undeclared privileged capability names. Never directly reference
`window.ClusterCEXP` or `window.ClusterTerminal` in untrusted plugin.
No credentials, machine paths, copied Local Agent config or bypass.
