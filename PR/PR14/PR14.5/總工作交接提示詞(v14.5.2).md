OCDA model design:
- PluginLocalAgentObject owns pinned loopback WebSocket, token pairing
  and host-owned model API key dialog; no keys in Hub payload, Worker,
  iframe, OMU Log or browser storage. Old Agent may persist local
  plaintext provider JSON; at-rest encryption not verified.
- PluginModelTaskObject owns transient per-task UUID and state, calls
  LocalAgent via Hub Req/Rep, processes only transport-origin
  ingest/reset; PluginModelTaskPolicy validates bounded text/status.
- PluginUIHostUnit is the generic plugin UI extension; no AI-specific
  code in main.js, no HubUnit, URU, EDPMU or OMU core changes.
- Model task starts asynchronously, allowing cancel through another
  Hub Request while the Windows Agent waits on model inference.
- Unsolicited tool_call never executed. Explorer/PowerShell/MCP
  remain unauthorized pending PR14.6/14.7/14.8.
