PR8 大文本按需切片：P-tree 主層、B+ tree 輔助索引。
六層：虛擬化 address -> 切片載入/註冊 ->
前處理 plugins（著色/中文編碼/行號） ->
編輯窗口 -> 提交 plugins（MVCC/快捷鍵） ->
回寫並降級註銷。公用層支援復原所有層狀態。
定義狀態：
- 虛擬化：只保留可以讀取切片的位址與索引，不載入內容。
- 預載入：只保留切片資料，不執行第三/第五層 plugins。
- 完全載入：目前可見區切片，才套用編輯器與 plugins。
瀏覽窗口依當前 scroll viewport 與網頁縮放計算可見切片；
上下鄰近預載入，離開可見區時完全載入降級預載入，
距離更遠者解除註冊並退回虛擬化。
快速滑動與行跳轉要取消失效任務、優先最新位置，
避免第三層著色阻塞 UI；使用 Worker/切片排程設計，
必須做微切片與負荷測試。
藍色進度條只計算當次載入/轉換/儲存操作百分比，
不可把已載入文件比例當作當前操作完成度。

## OCDA 六原則與 LinkCore
每個 Object 含 EHU/Log、Request、Response、User API、
Agent API、Property、Program。跨物件 Req/Rep 由 HubUnit
路由，OMU 紀錄 EHU/Log/Dependency/200、400 等代碼。
URU 動態註冊並於重載清空；EDPMU 全域共享 Property。
Relation 00 無、10 Request、01 Response、11 雙向。
Public/Private/Protected；SubObject 繼承與完整路徑。
物件定 API（手），Property 定算法（大腦），
EventChain 能平行化則分離資源並行、同資源 FIFO。
禁止 SendTo，跨物件路由用 ObjectPath.Request.Action。
SystemVersion 等變數統一由 LinkCore 發佈。
