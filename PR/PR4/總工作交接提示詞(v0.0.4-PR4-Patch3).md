## OCDA 規範
Object = EHU/Log、Request、Response、User API、Agent API、
Property、Program；以物件為黑箱開發單位。
跨物件互動必須由 HubUnit 走 Request/Response。
OMU 記錄 HTTP-like 200/400/403/404/409/500/503、EHU、
Log、Dependency，PASS 去重 1 秒但不去重 FAIL/EHU。
URU 動態註冊，網頁重啟清空；EDPMU 全域共享 Property。
Relation Code 00/10/01/11；Public/Protected/Private；
子物件 Object.SubObject；禁止 SendTo()。
事件鏈的獨立資料可平行化，單文件同資源操作按序執行。
物件定義 API（手），Property 負責算法（大腦）。
LinkCore 統一發佈 SystemVersion 等動態資料。
