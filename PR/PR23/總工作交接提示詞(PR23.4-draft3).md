## NEW requirement PR23.4
All individual UI Object UISP APIs must support a 2-bit `UIOperationCode`:
00 Add extension API, 01 Delete extension API, 10 Query API, 11 Update extension API.
This is distinct from RelationCode (00 none, 10 Request, 01 Response, 11 bidirectional).
Operations are separately authorized by HubUnit; the 2-bit code is NOT an ACL mask.
Native UI APIs are never deletable by default; exceptional delete is a separate grant.
Provenance, owner, revision, schema, rollback, eventId and EHU are mandatory.
The planned UI.ExtensionAPI request is not yet implemented; do not expose prematurely.
