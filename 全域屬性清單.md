## Rules

1. Name each property uniquely and place its implementation in its own file.
2. EDPMU is authoritative for registry values and their life cycle.
3. HubUnit mediates cross-object property updates.
4. Public, Protected and Private authorization is pending enforcement.
5. No secrets, tokens or machine-specific absolute paths.
6. Never infer that a prototype property is production-ready.
