# 全域屬性清單 — ClusterOpt2 / PR1

Read this registry before implementing a new Object/Property.
Each property has a separate implementation and a single EDPMU registration.

| ID | Source | Owner | Visibility | Usage |
| --- | --- | --- | --- | --- |
| SystemVersion | LinkCore.js | LinkCore | Public | Centralized version |
| DocumentStatus | property/DocumentStatus.js | LinkCore | Public | All editor objects |
| AccessPolicy | property/AccessPolicy.js | LinkCore | Public | Hub authorization |
| ParallelExecutionPolicy | property/ParallelExecutionPolicy.js | LinkCore | Public | Scheduler algorithm |
| UI_COLOR | Implementation/property/UI_COLOR.js | LinkCore, InterfacePalette | Public | Global RGB value, CSS token algorithms, dark/light contrast |
| Language | Implementation/property/Language.js | LinkCore, LanguageManager | Public | Locale, translation catalogue and string interpolation |

All dynamic runtime property registration is coordinated by URU/Hub.
Access uses source Object identity and declared visibility.
Immutable property definitions are reusable; actions and privileged
updates must be routed through HubUnit, not arbitrary cross-object calls.

Files must avoid secrets, tokens, absolute machine paths and duplicated
global definitions. PR1 and PR2 have merged. PR3 is in development.

PR2: all UI objects must consume CSS variables published by the shared
UI_COLOR property rather than maintaining independent color definitions.

PR3: all UI Objects use the shared Language Property (zh-Hant/en). LanguageManager is its single writer via HubUnit; new locale dictionaries may be added without changing consumers.
