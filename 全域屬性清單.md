## PLUGIN PR03 version authority
`Implementation/property/ReleaseVersion.js` alone defines the product
version. `SystemVersion` and `Cluster.version()` read it through LinkCore.
`package.json` is a generated/verified distribution mirror; `npm run
version:check` is mandatory in CI and `npm run version:sync` updates it.
Draft subPRs do not publish new product versions. The guarded major-PR
release gate updates this one source and re-verifies all consumers.
